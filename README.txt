PORTFOLIO TEMPLATE

1. index.html is the main website. Edit it in GitHub using the pencil/Edit button.
2. Replace assets/profile.jpg with your own photo (keep the filename profile.jpg).
3. Put your CV PDF at documents/resume/resume.pdf (keep the filename or update the link in index.html).
4. Put certificate PDFs at documents/certificates/ and update certificate links/titles in index.html.
5. Edit LinkedIn URL, email, name, About, experience, skills, education, projects and contact in index.html.
6. This is a starter template; it is not an exact copy of the referenced portfolio.
